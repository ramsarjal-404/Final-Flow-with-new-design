# Pill input

## When to use
- `SearchField` to filter a table, list, card or dropdown-like panel by text ("Search users").
- `PillInput` for short inline values in toolbars and filter bars, optionally with an icon (e.g. `icon="filter"`).
- `soft` (filled `--surface-2`) when the input sits inside a white card; the default white pill on the washed page background.

## When not to use
- Fields in dialogs, drawers, wizards and settings forms: use `TextField` (46 px, radius 14) so the form is consistent.
- When the user needs a validation message: `PillInput` has no error or help slot — use `TextField`.
- Multi-line text: use `TextAreaField`.

## Anatomy
1. Wrapper `<label class="lf-field">`: vertical flex, 6 px gap.
2. Optional visible label `.lf-field__label`: 600 12.5/18 `--ink-2`.
3. Pill `.lf-input`: height 40 (`--input-h`), padding 0 14, radius 999 (`--r-pill`), 1 px `--border`, white `--surface`, 8 px gap.
4. Optional leading icon: 16 px, `--ink-3`.
5. Input: 500 13.5/20 `--ink`, placeholder 400 `--ink-4`.
6. `SearchField` only: `type="search"`, so the browser shows a 14 px × clear button (styled grey X) once there is text.

In a `.toolbar` the wrapper is 280 px wide (max 100 %).

## Variants and sizes
| Variant | Look | Use |
|---|---|---|
| default | White pill, 1 px `--border` | Toolbars on the page background |
| `soft` (`.lf-input--pill`) | `--surface-2` fill, transparent border; `--border` on hover; white on focus | Searches inside cards and panels. `SearchField` is soft by default (`soft={false}` turns it off) |

Sizes: one size, 40 px (`--input-h`).

## States
| State | Change |
|---|---|
| Hover | Border `--border-2` (soft: `--border`) |
| Focus (focus-within) | Border `--brand-300` + `--ring`; soft variant turns white |
| Filled | Search variant shows the native clear button |

There is no disabled or error state.

## Accessibility
- The whole pill is a `<label>`, so clicking anywhere focuses the input.
- Accessible name: `ariaLabel`, else `label`, else `placeholder`. Always give at least one; for a `SearchField` without a visible label pass `ariaLabel` ("Search users").
- `SearchField` sets `maxLength` 200 by default.
- The leading icon is decorative.

## Do and don't
| Do | Don't |
|---|---|
| `SearchField` with a specific placeholder: "Search reports" | "Type here…" or no placeholder and no `ariaLabel` |
| Filter as the user types (debounce heavy queries) | Make the user press a separate "Search" button for a local filter |
| Pill inputs in toolbars, `TextField` in forms | Mix pill inputs and 46 px fields in the same form |

## Example
```tsx
import { SearchField, PillInput } from '@lepide/ds-react';

<div className="toolbar">
  <SearchField value={q} onChange={setQ} placeholder="Search users" ariaLabel="Search users" />
  <PillInput icon="filter" value={ou} onChange={setOu} placeholder="Filter by OU" soft />
</div>
```

Plain HTML (with `@lepide/ds-css`):
```html
<label class="lf-field">
  <span class="lf-input lf-input--pill">
    <!-- 16 px search icon -->
    <input type="search" placeholder="Search users" aria-label="Search users">
  </span>
</label>
```
