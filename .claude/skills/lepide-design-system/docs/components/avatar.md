# Avatar

## When to use
- `Person` in table cells, detail panels and activity lists to show who did something ("CORP\\jsmith · Domain Admins").
- `Avatar` on its own where only the initials fit, for example a stack of owners or a narrow column.

## When not to use
- The signed-in user's account button in the sidebar or top bar: those use their own ink avatars (`.lf-dock__avatar`, `.hometop__avatar`, `.umenu__av`).
- Non-person objects (servers, groups, files): use an `Icon` instead.
- Photos: `Avatar` only renders initials.

## Anatomy
**Avatar** (`.fx-av`)
1. Circle, 28 × 28 by default, 700 10.5/1 initials.
2. Tint: one of five, picked by a hash of `name`, so the same name always gets the same tint — `--brand-100` / `--brand` (`.fx-av`), `#e4efe9` / `#1d7a55` (`--1`), `#f6e7df` / `#a4552c` (`--2`), `#ece8f6` / `#5a4a9a` (`--3`), `#e6edf1` / `#3e6276` (`--4`).
3. Initials: up to two letters. Everything up to the last `\` or `@` is dropped (`CORP\john.smith` → `john.smith`), the rest is split on `.`, `_`, space and `-`, and the first letters of the first two words are used, upper-cased: "Ann Lee" → AL, `CORP\john.smith` → JS, `CORP\jsmith` → J. An empty name shows `?`.
4. Native tooltip: `title` is the full name.

**Person** (`.fx-who`): inline flex row, 10 px gap — a 28 px `Avatar`, then `.fx-name` (600, `--ink`, single line with ellipsis). `sub` follows the name as ` · sub` in 500 `--ink-4`.

Initials come from `initialsOf`: it drops a `DOMAIN\` prefix and an `@domain` suffix, then takes the first letters of the first two words split on `.`, `_`, `-` or spaces ("Ann Lee", "ann.lee@corp.com" and "CORP\ann.lee" all give "AL"; "CORP\jsmith" gives "J").

## Variants and sizes
`size` sets the width and height in px (default 28). It does not scale the 10.5 px initials, so keep sizes between 24 and 36. `Person` always uses 28.

## States
None.

## Accessibility
- The avatar is a `<span>` whose text is the initials; screen readers read the letters. In `Person` the full name follows, so the initials are redundant but harmless.
- On its own, `Avatar` exposes the full name only through `title`, which is not reliably announced. Put the name in visible text or an adjacent `sr-only` span.
- Tints are decoration; they carry no meaning.

## Do and don't
| Do | Don't |
|---|---|
| `Person` in table cells, with the group or role in `sub` | An initials avatar with no name anywhere |
| Pass a display name, `DOMAIN\user` or an email | Build initials yourself and pass them as `name` |
| Keep the 28 px default in tables | Large avatars with tiny initials |
| Let the hash pick the tint | Map tints to roles or risk |

## Example
```tsx
import { Person, Avatar } from '@lepide/ds-react';

<td><Person name={row.user} sub={row.department} /></td>

<span className="row">
  <Avatar name="Ann Lee" size={24} />
  <Avatar name="Raj Patel" size={24} />
  <span className="sr-only">Owners: Ann Lee, Raj Patel</span>
</span>
```

Plain HTML (with `@lepide/ds-css`):
```html
<span class="fx-who">
  <span class="fx-av fx-av--2" title="CORP\jsmith">J</span>
  <span class="fx-name">CORP\jsmith<i> · Domain Admins</i></span>
</span>
```
