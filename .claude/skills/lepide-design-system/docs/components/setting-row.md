# Setting row

## When to use
- Settings pages and settings cards: one row per setting, each with a title, an optional one-line explanation and its control.
- The control is usually a `Toggle`; a small `Dropdown` (`size="sm"`), `NumberField` or `Button` also fits.

## When not to use
- Data entry forms with many fields: use `Field` / `TextField` in a `.page-form`.
- Read-only key/value details: use a key/value list, not setting rows.

## Anatomy
1. Row `.setrow`: flex, items centred, space-between, 16 px gap, padding 14 0, 1 px `--border-soft` bottom border (none on the last row).
2. Text `.setrow__text`: title `<b>` 600 13.5/20 `--ink`; optional help `<span>` 400 12.5/18 `--ink-3`, on its own line.
3. Control slot: a `.row` wrapper (horizontal flex, items centred, 8 px gap) holding `children`, so several small controls line up.

## Variants and sizes
None. One size.

## States
None of its own; the control carries hover, focus and disabled states.

## Accessibility
- The title is plain text, not a `<label>`. Give the control its own accessible name that matches the title (e.g. `Toggle label="Email alerts"`).
- Keep the help text short; it is not linked to the control with `aria-describedby`.

## Do and don't
| Do | Don't |
|---|---|
| Title names the setting ("Email alerts"); help says what happens when it is on | Put the explanation in the title |
| One control per row | Several unrelated controls in one row |
| Group related rows in one card with a heading | One endless list of unrelated settings |

## Example
```tsx
import { SettingRow, Toggle, Dropdown } from '@lepide/ds-react';

<section className="lf-card">
  <SettingRow title="Email alerts" help="Send an e-mail when a critical alert is raised.">
    <Toggle label="Email alerts" checked={alerts} onChange={setAlerts} />
  </SettingRow>
  <SettingRow title="Digest frequency">
    <Dropdown size="sm" ariaLabel="Digest frequency" value={freq} onChange={setFreq} options={['Daily', 'Weekly']} />
  </SettingRow>
</section>
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="setrow">
  <div class="setrow__text"><b>Email alerts</b><span>Send an e-mail when a critical alert is raised.</span></div>
  <div class="row"><button type="button" class="lf-toggle" role="switch" aria-checked="false" aria-label="Email alerts"></button></div>
</div>
```
