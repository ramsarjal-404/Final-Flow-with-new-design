# Section nav

## When to use
- A page with several sections the user moves between, where each section is its own view: Settings categories, an admin area, a record with many sub-pages.
- Between 4 and about 20 sections. Group long lists with `group`.

## When not to use
- Two to five views of the same data: use `Segmented`.
- Sections inside a dialog: use `VerticalTabs`.
- Product-level navigation: that is the console sidebar (DESIGN.md §4.1).

## Anatomy
Place it as the first child of `<div className="settings">` (a 260 px sticky column + content grid) and put the content in `<section className="settings__body">`.
1. `nav.lf-card.snav`: white card, padding 14, sticky, scrolls when taller than the window.
2. Optional title `.snav__title` (700 15/22) and group headings `.snav__group` (600 11.5, `--ink-3`).
3. Items `.snav__item`: 38 px min-height, radius 10, 600 13/18 `--ink-2`, 16 px icon in `--ink-3`, optional badge `.snav__badge` (brand-50 pill).
4. Current item: `--sel-fill`, white text, `--sel-shadow`, `aria-current="page"`.
5. `.snav-select`: a pill `Dropdown` with the same options, shown instead of the card under 860 px.

## Variants and sizes
Items are buttons (`onChange`) or router links (`to`, rendered through `LepideProvider`'s link, which receives `aria-current`). One size.

## States
| State | Change |
|---|---|
| Rest | `--ink-2` text, `--ink-3` icon |
| Hover | `--surface-2` background, `--ink` text |
| Current | Selected finish, white text and badge |
| Narrow (≤ 860 px) | The card hides; the dropdown shows |

## Accessibility
- The `nav` is named by `ariaLabel`, else `title`, else "Sections".
- The current item has `aria-current="page"` (never colour alone: the finish is a filled block).
- With `to`, items are real links, so they open in a new tab and announce as links.

## Do and don't
| Do | Don't |
|---|---|
| Keep labels to one or two words | Long sentences that wrap |
| Use `to` with your router so the URL changes per section | Hold the section only in component state when it should be linkable |
| Show counts with `badge` sparingly | A badge on every item |

## Example
```tsx
import { SectionNav, PageHeader } from '@lepide/ds-react';

<div className="sub">
  <PageHeader crumbs={[{ label: 'Home', to: '/' }, { label: 'Settings' }]} title="Mail server and delivery" />
  <div className="settings">
    <SectionNav title="Settings" value={section} onChange={setSection} items={[
      { value: 'general', label: 'General', icon: 'sliders' },
      { value: 'mail', label: 'Mail server and delivery', icon: 'mail', to: '/settings/mail' },
      { value: 'sources', label: 'Data sources', icon: 'database', badge: 3, group: 'Data' },
    ]} />
    <section className="settings__body" aria-label="Mail server and delivery">…cards…</section>
  </div>
</div>
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="settings">
  <nav class="lf-card snav" aria-label="Settings">
    <p class="snav__title">Settings</p>
    <a class="snav__item" href="/settings/general"><svg class="lf-i" viewBox="0 0 24 24">…</svg><span>General</span></a>
    <a class="snav__item" href="/settings/mail" aria-current="page"><svg class="lf-i" viewBox="0 0 24 24">…</svg><span>Mail server and delivery</span></a>
    <p class="snav__group">Data</p>
    <a class="snav__item" href="/settings/exported-files"><svg class="lf-i" viewBox="0 0 24 24">…</svg><span>Exported files</span><span class="snav__badge">2</span></a>
  </nav>
  <!-- under 860 px the nav hides and this shows instead; in static HTML a native select is the fallback -->
  <div class="lf-field snav-select page-form"><div class="fld"><label class="fld__lbl" for="sec">Section</label>
    <select id="sec"><option>General</option><option selected>Mail server and delivery</option></select></div></div>
  <section class="settings__body">…</section>
</div>
```
