# Tile picker

## When to use
- Picking one type from 2–9 options that each need a short explanation or a logo: data-source type, policy template, report kind — typically the first step of a wizard.
- `multiple` when several can be chosen (connectors to enable).

## When not to use
- Plain options without descriptions: use `RadioGroup` (one) or a checkbox list / `MultiSelect` (many).
- Switching views: use `Segmented`.

## Anatomy
1. `.pick-grid` (`role="radiogroup"`, or `group` with `multiple`): auto-fill grid of tiles at least 200 px wide, 10 px gap.
2. Tile `.pick` (a button): padding 14, radius 14, 1 px `--border`, white.
3. `.pick__ic`: 36 px `--brand-50` tile with an 18 px brand icon, or a 24 px logo (`image`).
4. `.pick__text`: title `b` 700 13.5/18 `--ink`, description 500 12/16 `--ink-3`.
5. Chosen: `--brand` border and an 18 px round `.pick__check` with the selected finish at the top right.

## Variants and sizes
Single (radio) or `multiple` (pressed buttons). One size; the grid reflows.

## States
| State | Change |
|---|---|
| Hover | `--border-2`, `--sh-sm`, lifts 1 px |
| Chosen | Brand border + check (`aria-checked` or `aria-pressed`) |
| Disabled | Opacity .5, not-allowed cursor |

## Accessibility
- Single choice is a `radiogroup` of `role="radio"` buttons with `aria-checked`; multiple is a `group` of `aria-pressed` buttons.
- `ariaLabel` is required — it names the group ("Source type").
- The check mark adds a non-colour cue to the chosen tile.

The kit ships no vendor logos: use a line icon (`server`, `cloud`, `database`), or pass `image` with the product's logo
file when you have it. Don't mix icons and logos in one picker.

## Do and don't
| Do | Don't |
|---|---|
| A one-line description per tile | Paragraphs in tiles |
| Logos for third-party sources (`image`) | Mixing logos and icons in one grid |
| Pre-select the most common option when there is one | Leave a required single choice with nothing chosen and no hint |

## Example
```tsx
import { TilePicker } from '@lepide/ds-react';

<TilePicker ariaLabel="Source type" value={source} onChange={setSource} options={[
  { value: 'windows', label: 'Windows file server', description: 'NTFS shares on Windows Server', icon: 'server' },
  { value: 'netapp', label: 'NetApp filer', description: 'CIFS shares on ONTAP', icon: 'database' },
  { value: 'spo', label: 'SharePoint Online', description: 'Sites and document libraries', icon: 'cloud' },
]} />
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="pick-grid" role="radiogroup" aria-label="Source type">
  <button type="button" class="pick" role="radio" aria-checked="true">
    <span class="pick__ic"><svg class="lf-i" viewBox="0 0 24 24">…server…</svg></span>
    <span class="pick__text"><b>Windows file server</b><span>NTFS shares on Windows Server</span></span>
    <span class="pick__check" aria-hidden="true"><svg class="lf-i" viewBox="0 0 24 24">…check…</svg></span>
  </button>
  <button type="button" class="pick" role="radio" aria-checked="false">…</button>
</div>
```
