# Radio group

## When to use
- Exactly one choice from two to about six options that should all be visible at once (report format, scope "This OU / Whole domain").
- When the options need a moment of comparison before choosing.

## When not to use
- More than about six options, or long lists: use `SelectField` / `SearchSelect`.
- A compact switch between views in a toolbar: use `Segmented`.
- Independent on/off choices: use `Checkbox` or `Toggle`.

## Anatomy
1. Group `.lf-radio` (`role="radiogroup"`): vertical flex, 2 px gap. `.lf-radio--row`: horizontal, wraps, 6 px row gap, 16 px column gap.
2. Option row `<label>`: min-height 36, padding 0 10, radius 8 (`--r-xs`), 10 px gap, 500 13/18 `--ink-2`.
3. Native radio input, 15 × 15, `accent-color: var(--brand)`.
4. Option label text.

Options accept strings or `{ value, label, disabled }`. Every input shares one `name` (generated with `useId()` unless you pass `name`).

## Variants and sizes
None. Layout: stacked (default) or `row`. One size, 36 px rows.

## States
| State | Change |
|---|---|
| Hover | Row `--surface-2` |
| Checked | Row `--brand-50`, text `--ink`, brand-filled radio |
| Focus | Native radio focus ring (global 2 px brand outline) |
| Disabled option | Text `--ink-4`, no hover fill, not-allowed cursor |

## Accessibility
- Native radios: Tab moves into the group (to the checked option), ↑/↓/←/→ move and select within it, as the browser provides.
- Pass `ariaLabel` to name the group, or wrap it in `Field` with a label; the group has `role="radiogroup"`.
- The checked option is shown by the filled radio, not only the row tint.

## Do and don't
| Do | Don't |
|---|---|
| Preselect the safest or most common option | Leave a required group with no default unless a choice must be deliberate |
| Short, parallel labels: "CSV", "PDF", "Excel" | Long sentences as option labels |
| `row` for two or three short options | `row` with long labels that wrap unpredictably |
| `SelectField` past about six options | Ten radio rows in a dialog |

## Example
```tsx
import { Field, RadioGroup } from '@lepide/ds-react';

<Field label="Export format">
  <RadioGroup ariaLabel="Export format" row value={format} onChange={setFormat}
    options={['CSV', 'PDF', { value: 'xlsx', label: 'Excel' }]} />
</Field>
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="lf-radio" role="radiogroup" aria-label="Scope">
  <label><input type="radio" name="scope" value="ou" checked> This OU</label>
  <label><input type="radio" name="scope" value="domain"> Whole domain</label>
</div>
```
