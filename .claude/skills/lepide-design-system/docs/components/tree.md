# Tree

## When to use
- The left column of a hub (DESIGN.md §4.2 "Reports hub"): pick a folder, the table on the right shows its contents.
- Hierarchies two or three levels deep with counts.

## When not to use
- Flat lists of sections: use `SectionNav`.
- Choosing items for a form: use `MultiSelect` or a checkbox list.

## Anatomy
Put it in a card: `<Card title="Folders" className="folders">` (the reports layout `.reports` gives the 288 px column).
1. `ul.tree` (`role="tree"`), 2 px between rows.
2. Top-level rows: 38 px, radius 10, 600 13 `--ink-2`; a 16 px `folder` icon (or a chevron `.sign` when the row has children); label; count pill `.n` (20 tall, `--surface-3`, 700 11 tabular).
3. Nested rows: inside `ul[role="group"]`, indented 18 px behind a `--border` hairline; 32 px, radius 8, 500 13 `--ink-2`, 13–14 px icons in `--ink-4`. Nested rows with children are `li.grp`.
4. Current row (`value`): top level — selected finish, white text and count; nested — `--brand-50` with `--brand-ink` text.

## Variants and sizes
None. Disabled items (`disabled`) are `--ink-4` and can't be chosen.

## States
| State | Change |
|---|---|
| Hover | `--surface-2`; nested rows also turn `--brand` |
| Expanded | Chevron rotates 90°, children fade up |
| Current | See Anatomy 4 |
| Disabled | `--ink-4`, not-allowed cursor |

## Accessibility
- `role="tree"` / `treeitem` / `group`, with `aria-expanded` on rows with children and `aria-selected` + `aria-current` on the current row.
- Keyboard: ↑/↓ move between visible rows, → expands, ← collapses or moves to the parent, Home/End go to the first/last row; Enter/Space activate.
- Name it with `ariaLabel` ("Report folders").

## Do and don't
| Do | Don't |
|---|---|
| Show counts on folders | Counts on every nested item |
| Expand the current folder's group by default (`defaultExpanded`) | Open every group at once |
| Keep labels short; they truncate with an ellipsis | Long paths as labels |

## Example
```tsx
import { Card, Tree } from '@lepide/ds-react';

<Card title="Folders" className="folders">
  <Tree ariaLabel="Report folders" value={folder} onSelect={(f) => setFolder(f.id)} defaultExpanded={['fav']} items={[
    { id: 'all', label: 'All reports', count: 14 },
    { id: 'ad', label: 'Active Directory', count: 4 },
    { id: 'fs', label: 'File server', count: 6 },
    { id: 'fav', label: 'Favourites', count: 2, children: [
      { id: 'r1', label: 'User account lockouts' },
      { id: 'r2', label: 'Permission changes' },
    ] },
  ]} />
</Card>
```
