# Toggle

## When to use
- A single setting that is on or off and applies as soon as it is flipped (enable alerts, auto-refresh, mask sensitive data).
- Rows in a settings list — put it in a `SettingRow`, which supplies the visible title and help text.

## When not to use
- A choice that is only applied after "Save" or "Apply" in a form: use `Checkbox`.
- Choosing between named options ("Daily / Weekly"): use `RadioGroup` or `Segmented`.
- Agreeing to terms or selecting rows: use `Checkbox`.

## Anatomy
1. Track: `<button class="lf-toggle">`, 38 × 22 (`--toggle-w` × `--toggle-h`), pill radius, no border. Off `--toggle-off`, on `--brand`.
2. Knob (`::after`): 16 px white (`--surface`) circle, 3 px inset, soft two-layer shadow. Slides 16 px to the right when on (250 ms `--ease-out`).

The component renders no visible text; the label is supplied for screen readers only. Place visible text next to it (or use `SettingRow`).

## Variants and sizes
None. One size, 38 × 22.

## States
| State | Change |
|---|---|
| Off | Track `--toggle-off`; hover `--toggle-off-hover` (darker greys in the dark theme) |
| On | `aria-checked="true"`, track `--brand`, knob at the right |
| Pressed | Knob stretches to 20 px wide (toward the centre when on) |
| Focus | Global 2 px brand outline (`--focus-outline`), offset 2 px |
| Disabled | Opacity .45, not-allowed cursor (inline style), `disabled` attribute; clicks do nothing |

## Accessibility
- Renders `<button type="button" role="switch" aria-checked>`; Space and Enter toggle it (native button behaviour).
- `label` is required and becomes `aria-label`. When a visible title sits next to it, use the same words.
- `id` lets you point a visible `<label htmlFor>` or `aria-describedby` at it.
- On/off is shown by knob position as well as colour.

## Do and don't
| Do | Don't |
|---|---|
| Apply the change immediately and confirm with a toast if it has side effects | Require a Save button after flipping a toggle |
| `label` that names the setting: "Email alerts" | `label="Toggle"` or "On/Off" |
| Use inside `SettingRow` with a short help line | A toggle with no visible text anywhere |
| `Checkbox` inside forms that are submitted | Mix toggles and checkboxes for the same kind of choice in one form |

## Example
```tsx
import { Toggle, SettingRow } from '@lepide/ds-react';

<SettingRow title="Email alerts" help="Send an e-mail when a critical alert is raised.">
  <Toggle label="Email alerts" checked={alerts} onChange={setAlerts} />
</SettingRow>
```

Plain HTML (with `@lepide/ds-css`):
```html
<button type="button" class="lf-toggle" role="switch" aria-checked="true" aria-label="Email alerts"></button>
```
