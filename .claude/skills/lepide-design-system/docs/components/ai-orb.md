# AI orb

## When to use
- The Lepide AI card on Home (`.ai-hero`): the orb sits at the left of the card, 168 px (120 px on phones).
- The Lepide AI chat welcome (`.welcome__orb`, 144 px).

## When not to use
- As a loading spinner or decoration anywhere else: it stands for Lepide AI only.
- Small sizes (under ~96 px): use the `ai` module icon (`<ModuleIcon name="ai" />`) instead.
- Never rebuild it with CSS (`conic-gradient` rings, spinning borders). It is a WebGL shader from the prototype;
  a CSS copy looks flat and `validate_code` reports it (`ai-orb`).

## Anatomy
1. A square box (`.orb-container`) sized by its class or `size`. The canvas fills it and draws its own glow, so the
   box is larger than the visible ring; the home card's class pulls it in with negative margins.
2. The ring: three colours from the theme, `--brand`, `--ai-glow` and `--brand-700`, re-read when
   `<html data-theme>` changes. White is the shader's transparency key, so the card's pastel mesh shows through.

## Variants and sizes
| Where | Class | Size |
|---|---|---|
| Home, Lepide AI card | `ai-hero__orb` | 168 px, margin −12 px −8 px (120 px under 620 px) |
| Lepide AI chat welcome | `welcome__orb` | 144 px |

## States
| State | Change |
|---|---|
| Intro | Grows in over 1.1 s when first shown, and again when it scrolls back into view |
| Pointer near | The ring leans toward the pointer and brightens |
| Click | A pulse runs through the ring |
| Reduced motion | No drift, no follow, no intro: a still ring |
| No WebGL2 | `.orb--fallback`: a still CSS ring in the same colours (the only CSS ring allowed) |
| Off screen / tab hidden | Stops drawing |

## Accessibility
- Decorative: the box is `aria-hidden`. The card's title ("Lepide AI") names what it stands for.
- Honours `prefers-reduced-motion`.

## Do and don't
| Do | Don't |
|---|---|
| `<AiOrb className="ai-hero__orb" />` in the Lepide AI card | A `div` with a `conic-gradient` border that spins |
| Let the theme colour it | Pass other colours |
| One orb per view | Several orbs, or the orb as a bullet or avatar |

## Example
```tsx
import { AiOrb } from '@lepide/ds-react';

<section className="ai-hero lf-card" aria-labelledby="ai-title">
  <AiOrb className="ai-hero__orb" />
  <div className="ai-hero__body">
    <div className="ai-hero__top"><h2 id="ai-title">Lepide AI</h2></div>
    <p className="ai-hero__text">Find critical files fast and stay secure — the Lepide AI way.</p>
    {/* ask pill and suggestion chips: DESIGN.md §4.2 Home */}
  </div>
</section>
```

Plain HTML: put an empty box where the orb goes and load the art script once (it mounts every `[data-lepide-orb]`):

```html
<div class="ai-hero__orb" data-lepide-orb></div>
<script src="https://lepide-new-ds.vercel.app/ds/lepide-art.js" defer></script>  <!-- or @lepide/ds-css/dist/lepide-art.js -->
```

From code: `Lepide.mountOrb(element)` (static pages) or `mountThemedOrb(element)` from `@lepide/ds-css/art`.
