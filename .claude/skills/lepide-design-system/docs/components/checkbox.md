# Checkbox

## When to use
- Independent yes/no choices in a form that are applied when the form is saved ("Include sub-OUs").
- A list of options where any number can be chosen.
- Row selection and "select all" headers in tables (`indeterminate` when some rows are selected).

## When not to use
- A setting that applies immediately: use `Toggle`.
- Exactly one choice from a set: use `RadioGroup`.
- Many options in a compact space: use `MultiSelect`.

## Anatomy
1. Wrapper `<label class="lf-check">`: inline flex, 10 px gap, min-height 28, 500 13/18 `--ink-2`, pointer cursor, no text selection.
2. Native `<input type="checkbox">`, visually hidden (1 × 1 px, opacity 0) but focusable.
3. Box `.lf-check__box`: 16 × 16 (`--check-size`), radius 5, 1.5 px `--border-2`, white `--surface`.
4. Tick (checked): white 4 × 8 check mark with 2 px strokes. Bar (indeterminate): white 2 px horizontal bar.
5. Optional label text.

## Variants and sizes
None. One size, 16 px box.

## States
| State | Change |
|---|---|
| Hover | Box border `--ink-3` |
| Checked | Box filled `--brand`, white tick |
| Indeterminate | Box filled `--brand`, white bar. Applied only while `checked` is false |
| Focus (keyboard) | 2 px brand outline around the box (same colour as `--focus-outline`), offset 2 px |
| Disabled | Box `--surface-3` with `--border`; label `--ink-4`, not-allowed cursor |

## Accessibility
- A real checkbox inside a `<label>`: clicking the label or box toggles it; Space toggles when focused.
- With no visible `label`, pass `ariaLabel` (e.g. "Select row DC01").
- Indeterminate is set on the DOM element (`el.indeterminate`), so screen readers announce "mixed".
- Checked state is shown by the tick, not colour alone.

## Do and don't
| Do | Don't |
|---|---|
| Phrase labels positively: "Send a weekly summary" | Negative labels: "Don't send a summary" |
| `indeterminate` on a parent when only some children are checked | Show a parent as checked when only some children are |
| `ariaLabel` on checkboxes in table rows | Unlabelled checkboxes |
| Use for choices saved with the form | Use for instant-apply settings (that's `Toggle`) |

## Example
```tsx
import { Checkbox } from '@lepide/ds-react';

<Checkbox label="Include sub-OUs" checked={subOus} onChange={setSubOus} />
<Checkbox ariaLabel="Select all rows" checked={allSelected} indeterminate={someSelected} onChange={toggleAll} />
```

Plain HTML (with `@lepide/ds-css`):
```html
<label class="lf-check">
  <input type="checkbox" checked>
  <span class="lf-check__box" aria-hidden="true"></span>
  <span>Include sub-OUs</span>
</label>
```
