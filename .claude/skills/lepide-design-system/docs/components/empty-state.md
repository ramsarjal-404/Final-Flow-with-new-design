# Empty state

## When to use
- A list, table or panel has nothing to show yet ("No reports yet").
- A search or filter returns no results ("No events match these filters").
- A section failed to load: `tone="error"`, with a retry action.
- `compact` inside small cards and panels.

## When not to use
- While data is loading: use `SkeletonRows` or `PageLoader`.
- Inside `DataTable`, don't render it beside the table: pass it to the table's `empty` prop, for first use (no rows at all). When search or filters leave no rows, the table shows its own `noResults` line instead (`.empty-cell`); if you filter `rows` yourself, also pass `filtered`. Outside a table (a filtered card grid, a chart with no data), an `EmptyState` with "Clear filters" is the no-results state.
- A page-level notice that sits above content that is still shown: use `Banner`.
- Transient confirmation of an action: use a toast.

## Anatomy
1. Field (`.empty`): flex column, centred, 10 px gap, padding 48 24, min-height 300, 12 px margin, radius 14 (`--r-md`), `flex: 1`. Background: 1 px dots every 18 px over `--surface-2`, edges faded with a radial mask. Text 400 14/21 `--ink-3`.
2. Icon tile (`.ring`): 56 × 56, radius 18, `--surface` fill, `--brand` icon, `--sh-md` plus a 1 px inset `--border-soft` ring, a slow pulsing `ring-out` halo (2.4 s, infinite). The icon (`icon`, default `folder`) is 24 px (`--icon-lg`).
3. Title (`title`): `<h4>`, 700 18/26, −0.02em, `--ink`.
4. Message (`message`): `<p>`, max 46ch, 8 px bottom margin.
5. Action (`action`): any node, usually one `Button`.

## Variants and sizes
| Variant | Change |
|---|---|
| Default | As above |
| `compact` | Min-height 160, padding 28 20; icon tile 44 × 44 with a 20 px icon; title 600 15/22 |
| `tone="error"` | Adds `.empty--error`: icon tile `--danger-bg` fill with a `--danger-text` icon. The icon defaults to `alert` but an explicit `icon` wins. Combines with `compact` (`.empty--compact`: 44 px tile, 20 px icon, 160 px min-height) |

Dark theme: the dots are drawn in 8 % white.

## States
None. The `ring-out` pulse stops after one cycle under `prefers-reduced-motion`.

## Accessibility
- Renders a plain `<div>` with an `<h4>` title. It is not a live region: if the empty or error state replaces content after a user action, announce it yourself (for example with a toast or an `aria-live` wrapper).
- The icon is decorative (`aria-hidden`).
- Pick the heading level context carefully: the title is always `<h4>`.
- The action is focusable as usual; make its label say what it does ("Create report", "Try again").

## Do and don't
| Do | Don't |
|---|---|
| Say what is empty and what to do next | "No data" with no explanation |
| Name what didn't match: `No reports match "finance".` (generic: `No results match your search or filters.`) | "Sorry, …", Title Case or exclamation marks |
| One action that fixes the state ("Clear filters", "Add server") | Several competing buttons |
| The action is secondary when the page header already has the primary (the same "Add server"); primary only when the view has no other | A second primary in the empty table under the header's primary |
| `tone="error"` with a "Try again" action for load failures | A red banner and an empty state for the same error |
| `compact` inside cards | A 300 px tall block in a small panel |

## Example
```tsx
import { EmptyState, Button } from '@lepide/ds-react';

{rows.length === 0 && (
  <EmptyState
    icon="filter"
    title="No events match these filters"
    message="Widen the date range or remove a filter to see more results."
    action={<Button onClick={clearFilters}>Clear filters</Button>}
  />
)}

{error && (
  <EmptyState
    compact
    tone="error"
    title="Couldn't load this panel"
    message={error.message}
    action={<Button icon="refresh" onClick={retry}>Try again</Button>}
  />
)}
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="empty">
  <span class="ring"><svg class="lf-i" viewBox="0 0 24 24" aria-hidden="true">…</svg></span>
  <h4>No reports yet</h4>
  <p>Create a report to start tracking changes.</p>
  <button class="lf-btn lf-btn--primary">Create report</button>
</div>
```
