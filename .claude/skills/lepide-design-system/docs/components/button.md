# Button

## When to use
- `Button` for any action the user starts: save, create, export, open a dialog, apply a filter.
- `variant="primary"` for the single main action of a page, dialog, drawer or wizard step.
- `IconButton` for compact, repeated or toolbar actions where an icon is unambiguous (close, refresh, more, row actions).

## When not to use
- Navigation to another page: use a link (`<a className="lf-link">` or your router link), not a button.
- Choosing one of several options: use `Segmented`, `RadioGroup` or `Dropdown`.
- More than one primary in the same view — demote the others to `secondary`.
- A black or ink-filled button: the design has none.

## Anatomy
1. Pill container: height 38 (`--btn-h`), padding 0 16, radius 999, 1 px border, `--sh-xs`.
2. Optional leading icon, 16 px, 8 px gap (replaced by a 15 px spinner while `loading`).
3. Label: 600 13/1 Manrope, sentence case, a verb ("Create report", "Save").
4. Optional trailing icon (`iconEnd`), 14 px — e.g. a chevron for buttons that open a menu.
5. Optional brand dot (`dot`): 8 px, top-right, 2 px white ring — "this has something applied".

`IconButton`: 34 × 34 round, transparent, 16 px ink-3 icon; `bordered` adds a 1 px border, white fill and `--sh-xs` (class `is-bordered`, so plain HTML can use it too).

## Variants and sizes
| Variant | Look | Use |
|---|---|---|
| `secondary` (default) | White, 1 px `--border`, ink text | Every non-primary action |
| `primary` | `--sel-fill` blue gradient, `--brand-600` border, white text, `--sh-brand` glow | The one main action, rightmost |
| `ghost` | Secondary with 500-weight ink-2 text (`.lf-pill`) | Low-emphasis actions in toolbars |
| `danger` | Secondary with danger text and red-tinted border | Destructive action that still asks for confirmation |
| `danger-solid` | `--danger` fill, white text, red glow | Confirm button inside a destructive `ConfirmDialog` only |

Sizes: `sm` 32 tall, padding 0 13, 12.5 px · `md` 38 (default) · `lg` 44 tall, padding 0 20, 14 px. `block` stretches to full width.

## States
| State | Change |
|---|---|
| Hover | Secondary: `--border-2`, `--surface-2`, `--sh-sm`. Primary: darker gradient, `--brand-700` border, bigger glow; its icon nudges 1 px right |
| Pressed | `scale(.97)` for 80 ms; primary turns `--brand-700` |
| Focus | 2 px brand outline (`--focus-outline`), offset 2 px |
| Disabled | Opacity .45, no shadow, not clickable |
| Loading | Spinner replaces the leading icon, button disabled, `aria-busy="true"` |
| Icon button hover | `--surface-3` fill, icon turns ink; `danger` turns it red |

## Accessibility
- Renders a real `<button type="button">` (pass `type="submit"` inside forms).
- `IconButton` requires `label`: it becomes `aria-label` and the tooltip text (`TooltipHost` must be mounted once).
- Loading sets `aria-busy` and disables the button so it can't be pressed twice.
- Never rely on colour alone for danger — the label says what happens ("Delete 3 reports").

## Do and don't
| Do | Don't |
|---|---|
| One primary per view, placed last (rightmost) | Two primaries side by side |
| Verb labels in sentence case: "Create dashboard" | "OK", "Submit", Title Case Labels |
| `danger-solid` only as the confirm step of a destructive action | A red solid button as the first click |
| `loading` while an async action runs | Disable the button with no feedback |
| `IconButton` with a clear `label` | Icon-only buttons without a tooltip |

## Example
```tsx
import { Button, IconButton } from '@lepide/ds-react';

<div style={{ display: 'flex', gap: 8, justifyContent: 'flex-end' }}>
  <IconButton icon="refresh" label="Refresh" bordered onClick={reload} />
  <Button icon="download" onClick={exportCsv}>Export</Button>
  <Button variant="primary" icon="plus" loading={saving} onClick={create}>Create report</Button>
</div>
```

Plain HTML (with `@lepide/ds-css`):
```html
<button class="lf-btn">Cancel</button>
<button class="lf-btn lf-btn--primary">Save</button>
```
