# Banner

## When to use
- A notice that stays visible while the user works with the content around it: "Licence expires in 7 days", "This report includes only the last 90 days", "2 agents are offline".
- A form or dialog-level error or warning above the fields ("Couldn't connect to the SMTP server").
- A success message that should persist on the page (for example after an import, with a link to the results).

## When not to use
- Short-lived confirmation of an action: use a toast (`useToast`).
- A field-level validation message: use the field's `error`.
- An empty or failed section with nothing else to show: use `EmptyState`.
- Marketing or promotional content.

## Anatomy
1. Container (`.banner`): flex row, items aligned to the top, 10 px gap, padding 10 14, radius 14 (`--r-md`), 500 13/19 `--ink-2` text, tone background.
2. Tone icon: 16 px, 2 px top offset, tone colour. `info` → `info`, `success` → `check`, `warning` and `error` → `alert`.
3. Message (`children`) in a `.grow` block that takes the remaining width; `<b>` inside it is `--ink`.
4. Optional action (`action`): any node after the message, usually a small `Button` or a `.lf-link`.
5. Optional dismiss button (when `onClose` is set): 26 × 26 icon button (`.lf-btn--icon.banner__x`) with a 14 px `x`, `aria-label="Dismiss"`.

## Variants and sizes
| Tone | Background | Icon colour | Role |
|---|---|---|---|
| `info` (default) | `--brand-50` | `--brand-ink` | `status` |
| `success` | `--success-bg` | `--success-text` | `status` |
| `warning` | `--warning-bg` | `--warning-text` | `alert` |
| `error` | `--danger-bg` | `--danger-text` | `alert` |

The text stays `--ink-2` in every tone; only the background and icon change. One size.

## States
| State | Change |
|---|---|
| Dismiss button hover | `--surface-3` fill, icon turns `--ink` (icon button hover) |
| Dismiss button focus | 2 px brand focus outline |

The component does not hide itself: `onClose` is called and you remove the banner from your state.

## Accessibility
- `warning` and `error` use `role="alert"` and are announced immediately when they appear; `info` and `success` use `role="status"` (polite). Don't mount several alert banners at once.
- The message must make sense without the colour or icon: start with what happened ("Couldn't connect…", "Licence expires…").
- The dismiss button is named "Dismiss"; with `TooltipHost` mounted it shows that name as a tooltip.
- After dismissing, move focus somewhere sensible if the banner had focus.

## Do and don't
| Do | Don't |
|---|---|
| One banner per area, at the top of the content it is about | A stack of banners |
| Plain sentences with the key fact in `<b>` | All-bold or all-caps text |
| `warning` / `error` only for real problems | `error` tone for neutral information |
| A clear action: "Renew licence", "View agents" | "Click here" |

## Example
```tsx
import { Banner, Button } from '@lepide/ds-react';

<Banner
  tone="warning"
  action={<Button size="sm" onClick={openLicensing}>Renew licence</Button>}
  onClose={() => setShowLicence(false)}
>
  Your licence expires on <b>14 November 2026</b>. Auditing stops after that date.
</Banner>

<Banner>This report shows changes from the last <b>90 days</b>.</Banner>
```

Plain HTML (with `@lepide/ds-css`):
```html
<div class="banner banner--error" role="alert">
  <svg class="lf-i" viewBox="0 0 24 24" aria-hidden="true">…</svg>
  <div class="grow">Couldn't connect to the SMTP server.</div>
</div>
```
